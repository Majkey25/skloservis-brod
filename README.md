# Sklo Service Brod

Astro replacement for SKLOSERVIS-BROD s.r.o. Built on the same static architecture as [WeTheGods](https://github.com/Majkey25/WeTheGods): Astro, TypeScript, YAML content, Pages CMS and GitHub Actions.

Preparation is in progress. Frontend design and implementation start on 17 October 2026 at 21:05 Europe/Budapest. The current WordPress website and domain remain unchanged.

## Local development

Use Node.js 24.

```sh
npm ci
npm run dev
npm run check
npm test
npm run build
```

Editable content lives in `src/data`. Enquiries use `skloservis.brod@gmail.com`, confirmed by the owner. Form delivery requires a verified service before it can be called operational.

See `docs/agents/LAUNCH.md` for the implementation brief and `docs/agents/STATUS.md` for current evidence and remaining work.
